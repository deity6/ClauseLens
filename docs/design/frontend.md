## 1. 气质

**「验光单 / 鉴定报告」**：像一份被认真盖章的检验报告，而不是 SaaS 后台。
- 底色：暖纸 `#f4f1ea`（不是纯白）；墨色 `#1b1a17`；发丝线 `rgba(27,26,23,.12)`。
- 语义色只用于标签与等级，面积克制：
  - 好 `--good #2f7d5b`（苔绿）· 注意 `--warn #b7791f`（琥珀）· 坏 `--bad #c2412d`（朱砂）· 中性 `--neutral #6b6a64`
  - 等级 A→E：苔绿 → 青绿 → 琥珀 → 橘 → 朱砂。
- 字体：标题／站名／章节标题用**霞鹜文楷**（`"LXGW WenKai", "Kaiti SC", "STKaiti", "KaiTi"`，楷书笔锋，自托管 woff2 分片）；
  大数字用 **Instrument Serif**；元数据用小号 Space Mono；正文用系统黑体（苹方 / 微软雅黑）。
  **不用宋体**（原 `Noto Serif SC` / `Songti SC` 链已废弃），正文也不挂中文字体 webfont——首屏体积优先
  （`"Inter", "PingFang SC", "Microsoft YaHei", system-ui`），元数据等宽小字大写字距 .14em。
- 层级靠线 + 字号跳跃 + 留白，不靠大色块卡片堆；结果页可以有"印章"作为唯一的强装饰。
- 深色模式（点阵主题）：**桌面不跟随系统**，默认浅色、手动拨开关才切（选择存 `localStorage['cl:theme']`）；
  **手机 / 平板**在用户没手动选过时跟随 `prefers-color-scheme`（系统深色→点阵，浅色→纸），系统中途变化也跟。
  首帧由 `index.html` 里的内联脚本在 CSS 之前定 `data-theme`（避免先闪一下浅色）；CSP 是 `script-src 'self'`，
  脚本的 sha256 由 `scripts/csp-hash.mjs` 在 build 前自动写进 `public/_headers`（不要手改 hash）。
  `<html>` 上不写死主题值，React 侧（`lib/theme.js` 的 `getTheme`）只在引导脚本真跑过（`data-theme-boot` 存在）时才沿用。

## 2. 页面与流程（单页三态）

### 态 A · 首页（低门槛）
- 一句话标题：「**注册前，先看看你同意了什么**」；副标题一句解释（≤30字）。
- 一个大输入框：placeholder「输入网站，比如 baidu.com 或条款页面的网址」，回车即查。
  - 输入时实时提示模式：识别到纯域名 → 小字「整站查找条款」；识别到带路径 URL → 「只分析这一页」。
- 输入框下方：热门示例 chips（百度、淘宝、微信、抖音、GitHub、Google），点击即查。
- 再下方三步说明（图标 + 一句话）：找到条款 → 逐条阅读 → 给出标签和评分。
- 页脚免责声明：「结果由程序自动分析，仅供参考，不构成法律意见。」

### 态 B · 等待（重点：真实、俏皮、精细）
- **进度必须由后端 SSE 事件驱动**（见 `contract.md §3`），不是假进度条。阶段轨道：
  `找到网站 → 翻找条款 → 逐条阅读 → 打分盖章`，当前阶段有呼吸光点，已完成阶段打勾（描边动画）。
- 中央视觉：一张"文档纸"从下方滑入，扫描线（放大镜/透镜）从上到下扫过，扫到的行高亮；
  每收到一个 `tag` 事件，就从纸上"拎出"一个小标签飞到旁边的托盘里（好=绿、坏=红），形成"边找边亮"的感觉。
- 每收到 `document` 事件：显示一张小卡「隐私政策 · 3.2 万字 · 正常人要读 54 分钟」并计数器滚动。
  累计显示「已替你省下 87 分钟」。
- 俏皮文案轮播（每 2.6s 换一句，淡入上移），随阶段切换文案池，例如：
  - 翻找：「正在页脚角落里翻找那行灰色小字…」「条款通常藏在最不显眼的地方」
  - 阅读：「正在逐字阅读，比律师便宜一点」「发现一处“包括但不限于”，眉头一皱」「读到第 N 条了，你本来要读 54 分钟」
  - 打分：「正在盖章，请勿晃动」
- 取消按钮（中断 SSE），失败时有友好错误态 + 建议（试试直接粘贴条款网址）。
- `prefers-reduced-motion`：扫描线和飞行标签改为淡入淡出，轮播保留。

### 态 C · 结果
自上而下：
1. **报告头**：网站名 + favicon + 域名；右侧一个**等级印章**（大字母 A–E，圆形双环印章，盖下时有 scale 1.3→1 + 轻微旋转 + 墨迹扩散的动画，盖下后整个报告头轻微震一下）。下方分数 0–100 计数滚动。
   一行元数据：`共 3 份文档 · 5.2 万字 · 阅读需 87 分钟 · 适用：中国大陆（个人信息保护法…）`。
   若有 ToS;DR 社区评级，显示小字对照「ToS;DR 社区评级：E」。
2. **一句话总结（TL;DR）**：3–5 条，坏的在前，前面带色点。
3. **标签墙**：分「需要注意」「还不错」「一般说明」三组。每个标签是胶囊：图标 + 名称；进场错峰弹入（stagger 40ms，回弹曲线）。
   hover 微抬起 + 阴影 + 颜色加深（≥3 属性）。点击展开抽屉/手风琴：
   - 「这对你意味着什么」explain_zh
   - 原文证据（引号样式，关键词高亮），「来自：隐私政策」，可展开更多证据
   - 置信度小条 + 来源（规则/模型）
   - **投票**：「你认同这个判断吗？👍 认同 / 👎 不认同」+ 社区计数。**投了还能改**：点同一项撤回、点另一项改投，数字立刻跟着动
     （服务端计数 − 我上次那票 + 我现在这票）。同步攒着做：离开页面（`sendBeacon`）/ 下次打开 / 攒满 5 分钟才批量发一次，
     请求带的是「最终状态」（`vote:null` = 撤回），重复提交幂等；服务端按 IP 记一张「谁投了什么」的小表好把旧票退掉。
4. **六维雷达图**（隐私收集/数据共享/你的权利/平台权力/责任与纠纷/内容归属）：SVG 手写，多边形从中心生长展开，
   轴标签可 hover 显示该维度命中的标签。旁边配六条维度横条（数值 + 等级色）。
5. **合规检查清单**：「按 中国大陆 的法律要求，检查这些条款有没有写清楚」：每项 ✓ 找到 / ✕ 未找到，法条小字，
   找到的可展开证据。文案只能说「未在条款中找到」，不说「违法」。
6. **原文阅读器**（可折叠）：文档 tab 切换，标签证据在原文中高亮（点击标签证据可跳转滚动到原文位置并闪烁）。
7. 底部：「再查一个」按钮、分享（复制链接 `?q=baidu.com`）、免责声明。

## 3. 动效规范（全站共用）

- 缓动四件套（禁止现编）：默认 `cubic-bezier(.22,1,.36,1)`；进入 `cubic-bezier(.2,.7,.3,1)`；
  回弹 `cubic-bezier(.34,1.56,.64,1)`（只给缩放/弹入）；长尾 `cubic-bezier(.22,.61,.12,1)`（只给进度/填充）。
- 时长：微交互 160ms，状态切换 320ms，进场 520ms，印章 700ms。同类效果共用时长。
- 三态切换用 motion 的 `AnimatePresence`，整页过渡：旧态上移淡出，新态下方淡入；收束要有尾韵（轻微 overshoot 后停稳）。
- 数字滚动统一一个 `<CountUp>` 组件。

## 4. 技术

- React 19 + Vite 7 + `motion`（已装在 `frontend/node_modules`，`import { motion, AnimatePresence } from "motion/react"`）。
- 不引入 UI 组件库；样式用 CSS 变量 + 单个 `styles.css`（或 CSS modules）。
- 开发代理：`vite.config.js` 把 `/api` 代理到 `http://127.0.0.1:8787`。
- SSE：`new EventSource('/api/analyze?q=' + encodeURIComponent(q))`，监听 `stage/document/tag/result/error`。
- 标签字典：启动时 `GET /api/taxonomy`。
- URL 同步：`?q=` 参数，刷新或分享链接可直接复现查询。
- 移动端：≤640px 单列，印章缩小，雷达图居中；触控目标 ≥44px。
- 无障碍：颜色之外必须有图标/文字区分好坏；焦点环可见；`aria-live` 播报阶段。

## 5. 原文区的玻璃透镜（v3 契约）

- **它是什么**：`05 · SOURCE` 里那颗可拖的玻璃球。默认停在标题行右侧的 `.lensdock` 槽心（不做浮动小部件，
  不跟页面角落发生关系）；被拖走之后才是「屏幕上的放大镜」。
- **不变量**：
  1. **不许把球 clamp 进视口**。`dock` 不在视口里就整颗收起（`data-show=0`）——把 y 夹进 `innerHeight`
     的写法会让它在结果页一进来就贴在右下角（v2 的 bug）。
  2. **球心必须是透的**：66% 半径内不铺底色、不 `backdrop-filter`、不叠克隆。底下是活的 DOM（含原位译文），
     所以随便滚动都不会「卡在上一段」。玻璃感只由 66%→100% 的边缘折射环 + 亮边/暗环/色散/棱镜提供。
  3. **滚动就要重量**：`scroll` 监听用捕获阶段挂在 window（页面滚动与 `.reader__body` 内部滚动都收得到），
     先 `measure()` 再 `paint()`；正文 DOM 变了由 `MutationObserver` 置脏、下次同步重建边缘克隆。
  4. 译文一律「就地在原句位置」渲染（那条 `mark.hl` 的字变透明，canvas 画在它上面），不新增卡片、不碰排版；
     字号自适应、必要时往下多占一两行，颜色从可读中性色渐变到语义色（**不许从纯白起步**，纸底上会消失）。
- **位置存档**：`localStorage['cl:lens.v3']`，只存用户拖过之后的视口坐标；没拖过就始终跟 dock。
  `Home` 键与点凹槽都会清掉存档回位（`cl:lens:home` 事件）。
- **验收方式**：`node out/probe/lens-v3.mjs`（光/深两套主题）+ `lens-longdoc.mjs`（长文档内部滚动），
  截图落在 `out/shots/probe/`；真数据用 `?q=` 走 `http://127.0.0.1:4173`（preview 会把 `/api` 代理到本机后端）。
