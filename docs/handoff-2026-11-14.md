## 2. 投票（本轮主体）

**行为**：认同/不认同不再「点完定死」。点另一项 = 改投，点同一项 = 撤回；三个动作都只写本机、
界面立刻更新。真正的网络同步攒批做：

- `pagehide` / `visibilitychange:hidden` → `navigator.sendBeacon('/api/feedback/batch')`
- 下次打开结果页 → `loadVoteState()` 把没对齐的改动补发
- 页面一直开着 → 5 分钟兜底一次

请求体是「最终状态」：`{domain, votes:[{tag_id, vote:"agree"|"disagree"|null}]}`，`null` = 撤回。
幂等：重复提交同一状态不会多算，所以 beacon 丢了重发没关系。

**计数口径**（关键，别改错）：
界面数字 = 服务端计数 − 我上次同步上去的那一票 + 我现在这一票。
所以撤回时数字会立刻掉下来，而服务端计数还没变。

**后端**（`backend/clauselens/api.py`）：
- `_voted` 从 `set` 改成 `dict[(ip_hash|domain|tag)] = vote`；换票/撤回按「旧票减、新票加」调整 `_fb_counts`。
- `feedback.jsonl` 记录每次变更（撤回忆 `vote:null`），进程重启按顺序重放即可恢复计数与我的票。
- 新接口：`POST /api/feedback/batch`、`GET /api/feedback/state?domain=`（返回 `counts` + `mine`）。
- 老接口保留兼容：`POST /api/feedback`（现在幂等，不再 409）、`GET /api/feedback/summary`（仍是扁平 counts）。

**前端**（`frontend/src/lib/feedback.js`）：模块级 store + localStorage：
`clauselens.vote.{domain}.{tag}`（`agree`/`disagree`/`none`）、`clauselens.synced.{domain}.{tag}`（上次对齐值）。
`none` 是「撤回了」的留痕——直接删 key 会让 pending 找不到这条改动，撤回永远同步不上去。

## 3. 移动端主题（本轮修好）

之前线上一直判成浅色，三个原因叠在一起：
1. 线上 CSP 是 `script-src 'self'`，**内联首帧脚本被拦** → 先在 `<head>` 里引外部 `theme-boot.v2.js`；
   后来发现这个外链脚本是**阻塞请求**（在到 CF 边缘 1.3–2.2s 的链路上直接拖慢首画），又改回内联，
   并在 build 前用 `frontend/scripts/csp-hash.mjs` 把内联脚本的 sha256 写进 `public/_headers` 的 CSP（自动，不会漂）；
2. 文档开头 `matchMedia("(max-width:900px)")` 量到的是移动端默认 980px 视口 → 改用「移动 UA 或 粗指针 + `screen` 短边 ≤ 900」；
3. `<html data-theme="light">` 写死，React 会把「引导脚本没跑成」当成「算出来就是浅色」直接沿用 →
   去掉写死，`getTheme()` 只认 `data-theme-boot` 标记；脚本没跑成（被拦/网络失败）也能按规则自己算对。

（版本化文件名 + `_headers` 缓存那套已经作废：现在没有外链脚本了。CSP 里的 hash 由构建自动重算。）

## 4. 验证脚本（都在 `out/probe/`，不进仓库）

```powershell
# 后端先起在本机 8787、前端 preview 起在 4173（见上）
node out/probe/vote-accept.mjs     # 投票：即时/延迟同步/撤回/改投/清缓存认回，带断言
node out/probe/demo-vote.mjs       # demo（离线）模式：只写本机，/api/feedback 请求数 0
node out/probe/live-accept.mjs     # 线上：iPhone dark/light、系统中途切换、桌面不动
node out/probe/live-vote.mjs       # 线上 demo：投票/取消，截图
node out/probe/vote-ui-shots.mjs   # 两套主题下投票区的裁图
```

实测记录：
- 0/0 → 认同 1/0（后端未变）→ 刷新后后端 agree → 撤回 0/0（后端仍旧）→ 刷新后后端 0/0 →
  改投不认同 → 刷新后端 disagree → 清 localStorage 后从服务端认回「已记下」，全部断言通过。
- 线上 iPhone 模拟：dark→`geek`、light→`light`、会话中 light→dark 实时切；桌面 1440 开 dark 仍 `light`。
